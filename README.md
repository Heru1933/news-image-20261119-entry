THE WORLD TODAY: a program that draws a complete newspaper front page summing up Thursday 19 November 2026's world news in one 1024×1024 image — the Shenzhen trilateral summit as the lead, the ICJ's Myanmar genocide ruling, Anthropic's record IPO failing to lift Wall Street, the Senate's Iran war-powers vote, Voyager 1 reaching one light-day, and a briefs strip. It renders every pixel itself (own framebuffer, bitmap fonts and PNG encoder), Node standard library only, no network, fully deterministic.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```
